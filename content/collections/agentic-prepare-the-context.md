Prepare the Context examines how to give agent work a dependable basis in the system that actually exists.

[[agentic-ground-work-in-the-existing-system|Ground Work in the Existing System]] traces behavior and state boundaries, checks version-specific interfaces, and distinguishes setup failures from application defects. It develops three fictional cases rather than assuming that repository conventions are always correct.

[[agentic-keep-context-durable-and-discoverable|Keep Context Durable and Discoverable]] preserves stable guidance, decision rationale, and task evidence in discoverable places, with explicit freshness and handoff boundaries.
