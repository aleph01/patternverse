Choose the decision that matches the problem in front of you. These 39 patterns explain the intervention, show its consequences and describe when another approach is useful. Techniques and checks live with the decisions they support.

## Start with the problem

You do not need to know the family names first. Choose the symptom you can point to, then compare your design with the article’s examples. Start with one repair and check what it changes.

| What is happening? | Begin here |
| --- | --- |
| People cannot tell what the design is trying to say | [[graphic-design-define-the-core-message]] |
| Everything looks equally important | [[graphic-design-establish-visual-hierarchy]] |
| I cannot tell where to read next | [[graphic-design-establish-a-clear-reading-order]] |
| The page feels crowded, or the groups are unclear | [[graphic-design-use-spacing-to-express-relationships]] |
| Related elements have drifting edges and placements | [[graphic-design-align-to-common-edges]] |
| The text is tiring or awkward to read | [[graphic-design-typography]] |
| Text or a subject gets lost in its background | [[graphic-design-separate-figure-from-ground]] |
| Color is the only way to tell meanings apart | [[graphic-design-reinforce-meaning-beyond-color]] |
| The photograph looks good but adds little to the message | [[graphic-design-choose-images-for-meaning]] |
| Materials from one organization look unrelated | [[graphic-design-establish-a-shared-visual-language]] |
| People confuse the identity with another organization | [[graphic-design-develop-distinctive-visual-cues]] |
| Each new edition needs layout repairs | [[graphic-design-build-reusable-templates]] |

Two distinctions can help narrow the choice:

- **The route or the ideas?** Reading Order makes an intended sequence visible. If the ideas themselves need a different progression, begin with [[graphic-design-sequence-the-message|Sequence the Message]].
- **Faintness or interference?** If the light–dark difference is insufficient, begin with [[graphic-design-establish-value-contrast|Establish Value Contrast]]. If surrounding edges or texture break up the content, Figure–Ground separation addresses that boundary.
