Part of [[graphic-design|Graphic Design]]. How does the mind perceive visual elements as related, grouped, or distinct?

[[graphic-design-group-elements-within-shared-boundaries|Group Elements Within Shared Boundaries]] — enclose elements that belong to the same meaningful unit, keeping unrelated elements outside so the visible region expresses the intended membership.

[[graphic-design-signal-relationships-through-similarity|Signal Relationships Through Similarity]] — give elements that share a meaningful category or role a recognizable visual feature, and avoid sharing that feature where it would imply a false relationship.

[[graphic-design-establish-visual-continuity|Establish Visual Continuity]] — make the position and direction of separated marks support the intended continuation of a path or contour, while preserving meaningful breaks.

[[graphic-design-separate-figure-from-ground|Separate Figure from Ground]] — give the content that must read as a distinct object or layer a dependable boundary against its surroundings, using a ground that supports that distinction.

[[graphic-design-use-implied-forms|Use Implied Forms]] — leave parts of a visual form undrawn or hidden while retaining enough contour and identifying features for the intended whole to remain recognizable.
