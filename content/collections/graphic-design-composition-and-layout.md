Part of [[graphic-design|Graphic Design]]. How should visual elements occupy and relate within a space?

[[graphic-design-align-to-common-edges|Align to Common Edges]] — give related elements shared reference edges so their placement expresses a clear and dependable relationship.

[[graphic-design-establish-a-grid|Establish a Grid]] — define reusable margins, tracks, gutters, and spans so layout decisions form a coherent system that can adapt to content and format.

[[graphic-design-balance-visual-weight|Balance Visual Weight]] — distribute visual weight across a composition so its parts form an intentional whole while preserving meaningful emphasis.

[[graphic-design-use-spacing-to-express-relationships|Use Spacing to Express Relationships]] — allocate open space, relative distances and repeatable intervals so the layout expresses which elements belong together and where useful pauses occur.

[[graphic-design-establish-visual-rhythm|Establish Visual Rhythm]] — coordinate recurring elements and intervals through deliberate repetition, variation and pauses so the composition's pace supports its content.
