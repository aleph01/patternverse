        Start from explicit pretrained weights (1,−1,0), with no bias. Initial training is not
        simulated. Each C update uses a new record ID with identical flags and target. At every
        step, use the full frozen memory mean, not a sampled replay minibatch. Optimize (1−ρ) × new
        half squared error + ρ × mean memory half squared error, at learning rate 0.25. With an
        empty memory the effective replay weight is zero.
      

      

        Old MSE averages original A and B squared errors equally, regardless of buffer contents. New
        MSE evaluates C. These deterministic prototypes coincide with training inputs; errors are
        not held-out estimates. The matched current-only control uses learning rate 0.25 ×
        (1−effective ρ), omitting the memory gradient. It matches the new-data coefficient, not the
        replay run's overall objective.
      

      

        FIFO keeps the final capacity records of A1–A4 then B1–B4. Equal quotas reserve half the
        slots for each known historical cohort and keep its newest records. Reservoir fills its
        slots, then draws an index from the seen prefix and replaces a slot only when that index is
        below capacity. A Park–Miller seeded generator chooses a reproducible illustrative path; its
        seeds are not probability estimates. Ideal reservoir coverage below assumes genuinely
        uniform sampling without replacement.
      

      

        At two slots, 6 of 28 possible uniform subsets omit A and another 6 omit B. At four slots, 2
        of 70 omit a cohort. Quotas guarantee both only in this known, two-cohort fixture.
        Historical labels remain valid by assumption; no concept drift, buffer refresh during C,
        class expansion, privacy mechanism, or production stream is simulated.
