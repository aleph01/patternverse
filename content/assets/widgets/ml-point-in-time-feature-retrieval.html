Assumptions and scope

These are fictional scalar snapshots, not raw events to sum. Times share one date and UTC timezone; all comparisons include equality. Maximum age is decision time minus event time, not time since arrival. Original and corrected versions are retained. Ready time is assumed to be first availability on the actual prediction path; an upstream ingestion timestamp may be too early.

Within eligible rows, choose latest event time, then latest ready time, then highest source revision. The archive requires unique key/event/ready/revision combinations. This policy is deterministic and is not an audit of actual cache hits, outages, or online fallback behavior. A missing match returns null and preserves the decision row; no zero filling occurs.

Event-only retrieval intentionally ignores availability but still applies entity, event cutoff, and maximum age. Latest-in-archive intentionally ignores both the decision cutoff and maximum age, while keeping the entity key. Every archive row is known by the fixed 10:30 retrieval time. No model is trained, no accuracy is calculated, and no feature-store API is executed.
