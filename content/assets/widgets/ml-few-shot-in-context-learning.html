      Selection assumptions and limits
      

        Token sets contain lowercased ASCII letter sequences matched by [a-z]+. Punctuation
        separates words; repeated words count once; common words remain. Jaccard score =
        intersection size / union size; an empty union gets score zero. Ties use ascending example
        ID. Select the highest-scoring k, then optionally reverse only that selected set.
      

      

        This lexical heuristic is not semantic retrieval and does not reproduce KATE. Words such as
        “can” and “I” can create weak matches. Showing every label is a coverage fact, not evidence
        of better predictions. Zero-shot includes instructions and the new query with no
        demonstrations. Reversing order preserves selection and character count but changes the
        prompt sequence.
      

      

        There is no inference engine, learned embedding, model update, response probability, or
        hidden reference answer in the calculation. The conceptual fixed-model box describes how the
        prompt could be used elsewhere. Real inference effects need held-out evaluation with a
        specified model and generation settings. All data here is fictional.
