        Each row of S states which stores contribute to a series. W describes assumed base forecast
        errors, in squared units; it is not a covariance of observed demand. The profiles are
        invented, not estimated from residuals. For diagonal weights W = D. Correlated weights use W
        = D + v vᵀ, with v = (2, 1, −1, 1, 1, −1, −1). Positive diagonal D makes each matrix
        positive definite.
      

      

        The equal-weight method always uses W = I; bottom-up uses only the four store base
        forecasts. Their outputs ignore the error profile. Other methods minimize Q = (S b − base)ᵀ
        W⁻¹ (S b − base). The nonnegative option imposes b ≥ 0. Here a small exact face enumeration
        checks all 16 possible zero-store sets; it is not a scalable production solver.
