Raw words supply the targets. A tiny count model is fitted to five training lines, then scored on a different query. It learns no neural embeddings and measures no intent-classification performance.

Training data and exact rules

The training corpus is the following five lines. Both query sentences are excluded.

the parcel arrived late
the parcel arrived late
the parcel arrived early
the refund arrived safely
the refund arrived quickly

Tokenization splits these fixed lowercase sentences on spaces. All four words of each line become targets: 20 targets and eight vocabulary words. [BOS] and [EOS] are context markers, never targets. Duplicate lines contribute duplicate counts.

Next-token inputs are prefixes with no future tokens; this miniature predictor uses only the immediately preceding word. Masked-token inputs contain one [MASK]; this predictor uses only the immediate left and right words. It does not read the hidden target. Training and query use the same context rules.

For each vocabulary word, probability = (observed count + smoothing) / (context total + smoothing × 8). For an unseen context the probabilities are uniform. Target loss = −ln(target probability), in nats. The table sums to one before display rounding.

These objectives condition on different information, so their losses are not a ranking of representation quality. No downstream head is trained. The query target is used to score the prediction only; it is not added to training.
