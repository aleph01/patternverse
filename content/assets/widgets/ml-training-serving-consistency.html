Assumptions and optional calculation

Training rows are (0 km, standard), (0 km, express), (20 km, standard), (20 km, express). Fit a numeric mean and population standard deviation, ignoring missing numeric values. A constant feature uses scale one. T1 has mean 10 km, scale 10 km, and vocabulary [standard, express] in first-occurrence order. Vocabulary and feature order stay fixed at serving unless the deliberate reversal is selected. A missing distance is imputed with the active state's mean; a new service maps to its reserved unknown slot.

The live-batch error refits numeric statistics on the request's distance plus a second request at 40 km. Null is excluded from fitting. It keeps T1's vocabulary. Double normalization applies the saved numeric normalization to its own already-normalized result; this is an intentional unit/representation error. It does not repeat category lookup.

Feature order is [z, slot 0, slot 1, unknown]. The model expects standard in slot 0, express in slot 1, and score s = z + 0 × slot 0 + 2 × slot 1 − unknown − 2. Model p = 1/(1 + exp(−s)); flag when p ≥ 0.5. The coefficients and policies are teaching choices, not learned weights or calibrated deployment probabilities.

Feature parity uses absolute tolerance 10⁻¹² plus relative tolerance 10⁻⁹ times the saved-path magnitude. State comparison checks mean, scale and vocabulary; operation comparison also checks double normalization. A match on one vector does not certify all inputs or artifact compatibility. Reset restores the deliberately mismatched default and closes optional details.
