Exact predictor and test rules

Lowercase text and extract tokens matching a–z. The word sum uses good/great = +1 and bad/awful = −1. Other words have weight zero. Immediate-negation mode reverses a sentiment token's weight only if the preceding token is not. The shortcut adds the selected weight per mira token and subtracts it per noor token. Map the sum to s = 1 / (1 + exp(−sum)); classify positive when s ≥ 0.5, negative otherwise. The constant rule returns 0.25 for every input and ignores the disabled name setting.

Three labeled tests expect positive for good, negative for bad, and negative for not good. Two invariance pairs add Mira's attribution to good or Noor's attribution to bad; pass when |after − before| ≤ tolerance. Two directional pairs replace good with not good or append a second negative statement to bad; pass when after ≤ before. Numerical comparisons allow 1e-12 for floating-point roundoff.

The positive score is constructed, not a calibrated probability. Expected labels and relationships are fixed for these simple overall-sentiment cases; no oracle for arbitrary language is claimed. Non-increasing permits no change, so constant and negation-blind rules can pass it. A loose tolerance can hide a shortcut. No population accuracy, demographic fairness, learned capability, or production certification is measured.
