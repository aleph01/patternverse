Assumptions and metric definitions

Scores are hand-supplied values strictly between zero and one, not calibrated model probabilities. Each reviewed zero is a known negative. Labels always follow Billing, Access, Delivery order. Scores at or above the selected threshold are included. The forced-one rule ignores thresholds and resolves tied scores by label order.

Hamming loss counts wrong binary decisions divided by 12. Exact-set accuracy counts tickets with every label correct divided by four. Micro F1 pools true positives, false positives and false negatives before computing 2 × hits / (2 × hits + extra + missed). Macro F1 averages the three label F1 values. An undefined F1 is reported as N/A; macro F1 is N/A if any label F1 is undefined. All three labels have positives in this dataset.

Binary loss uses the supplied scores and reviewed labels, averaged over the inspected ticket’s three labels. Changing thresholds cannot change this loss or the scores. No training, threshold fitting, missing-annotation handling, hierarchy constraints or independent performance experiment runs. An empty prediction means no selected topic, not a proven out-of-vocabulary case or an abstention.
