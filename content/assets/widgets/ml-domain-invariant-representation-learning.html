For each encoder, fit the source task head by minimum 0–1 error among constants 0/1 and each coordinate's positive-threshold rule and its complement. Ties use that order, then coordinate order. Target labels never enter fitting, encoding, domain probing, or automatic selection; they are an oracle diagnostic only.

Lookup predicts each encoded value's majority domain on these same 16 records (ties choose source). The weak probe always predicts source. Equal domain sizes make chance 50%. Neither is a held-out estimate. Empirical total variation (TV) is half the sum of absolute differences between source and target encoded frequencies. The optimal lookup has accuracy (1 + TV)/2 on this balanced fixture.

These fixed encoders cannot establish real transfer, causal features, or a neural optimizer's behavior. The reversed-rule case changes target labels while leaving all observed features unchanged.
