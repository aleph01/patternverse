Exact data, fitting, and evaluation rules

The dataset has IDs A–H, two visits per ID, and labels from the eight digits above. Visit holdout trains on visit 1 and tests on visit 2 for every ID. Customer holdout puts both visits of the selected four IDs in test and both visits of the remaining IDs in training. Both have eight training rows and eight test rows.

The ID learner stores the majority label per training ID and uses the training majority for unknown IDs. The baseline always uses that same training majority. All ties predict zero. No held-out label is used when fitting either predictor; test labels only score the resulting predictions.

Changing the prediction question changes the interpretation, not the records or scores. For returning-customer use, visit-1 labels are assumed available before visit 2. Group holdout tests unfamiliar identities, but does not also test future-time drift or feature availability.

Both rows from a customer share a label and are dependent. The grouped test has eight rows but only four distinct customers. There is no transferable feature signal, confidence interval, label noise, or population-performance estimate in this tiny example. A perfect score alone cannot diagnose evaluation validity.
