x₁ is a broad shape score, x₂ a fine pattern score, and labels are the fictional reference classes. The features range over real numbers with no clipping. The toy radius is in these feature units, not pixel units. Original labels remain the evaluation references; no semantic label checker runs. Some opposite-label neighborhoods overlap at ε = 0.25, making perfect robustness impossible.

Score = w·x with zero bias; predict +1 at score ≥ 0, otherwise −1. Signed margin = y × score. Logistic loss = log(1 + exp(−margin)). Exact L∞ attack: δ = −εy sign(w), with sign(0) = 0. Exact L2 attack: δ = −εy w/‖w‖₂. These attacks minimize signed margin, hence maximize this linear logistic loss.

Worst margin = clean margin − ε‖w‖₁ for L∞, or clean margin − ε‖w‖₂ for L2. Robust accuracy counts records correct throughout their entire allowed neighborhood, with the stated score tie rule. This exact result is specific to the linear toy and these records; it is not a population estimate or a neural-network certificate. At zero radius, clean and worst-case quantities coincide.
