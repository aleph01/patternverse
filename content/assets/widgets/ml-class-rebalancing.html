Every defect record is repeated exactly the selected integer number of times. Original IDs are preserved. This deterministic teaching calculation is not random oversampling or synthetic data generation.

Assumptions and optional calculation

The three input groups are fixed before fitting. Counts (ordinary, defect) are Low (810,10), Middle (81,20), High (9,70). Each group has an independent constant score q. Fit by minimizing binary log loss with no regularization. With defect weight r and ordinary weight one, q = r × defects / (ordinary + r × defects). This is the exact optimum, not an iterative neural training simulation.

The weighted mean loss is the sum of weighted negative natural-log probabilities divided by total weight. All displayed losses use the selected weights so the comparison uses one objective. Multiplying every weight by a common positive constant leaves this normalized objective unchanged. Uniform integer repetition gives the same objective here; other learners, regularization, random samplers and optimization settings need not behave identically.

Metrics count original records, not weighted or repeated appearances. Recall = detected defects / all defects; precision = detected defects / all flags. Precision is N/A if nothing is flagged. Scores and drawing labels round; decisions use full precision and include equality at the threshold. No held-out or future performance is measured, no calibration is fitted, and threshold changes do not refit scores. Reset closes both optional explanations.
