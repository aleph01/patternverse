# Open Patternverse on this Mac

- Double-click **Open Patternverse Desktop.command** to bring up the installed macOS app.
- Double-click **Open Patternverse Web.command** to open the latest local web app at <http://127.0.0.1:5175/mira>. Keep the Terminal window it starts open while using the local web app; closing it stops that server.
- Double-click **Open Pattern Mark Studio.command** to open your private icon studio at <http://127.0.0.1:4202>. Review 100 deterministic grid icons, change families and variations, export SVGs and projects, or apply kept recipes to the local library. This editor is never part of the public website. The large-illustration editor remains in its second tab.

The published web app is at <https://patternverse.pages.dev/mira>. It is available without running a local server, but locally committed changes are not visible there until they are published.

If macOS warns about a downloaded launcher, open it from Finder with Control-click → Open. These launchers are plain text scripts in this folder and can be inspected before use.
