# Joke Mechanics

Patterns and structures in stand-up comedy.

The revised guide is imported as 42 Patternverse articles and 128 example placements in seven family collections. The existing `standup-comedy` Verse keeps its stable ID, is titled **Joke Mechanics**, and belongs to **Arts & Design** through the existing Area mapping. The main collection is `joke-mechanics` (**Joke Structures**).

`guide.json` preserves the source guide’s current articles, complete quotations, descriptions, citations and evidence qualifications. `import-manifest.json` records the source hash, article ID mapping, counts and generated paths. Run `node scripts/import-joke-mechanics.mjs` to regenerate this import. That command replaces only marked import files and the existing Verse; the earlier three pilot drafts remain unchanged.

The import retains 85 quotation placements, 43 descriptions, 82 distinct quotations and 36 embedded recording placements. `patternverse-video` blocks use the application’s existing YouTube player. Existing URL offsets are preserved; importing a timestamp does not establish that it was freshly checked.

The original structure-fit reports remain historical. This import changes format and navigation, not example wording or structural classifications. No new playback, source verification or audit is claimed.

Corpus status is `published` so these articles are included in the next production build. Adding these files does not itself deploy the public site.
