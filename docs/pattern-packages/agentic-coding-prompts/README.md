# Agentic Coding article prompts

Eighteen standalone prompts for the consolidated seven-collection catalogue. These are authoring instructions, not completed articles or a publication record.

## How to use

Open one article file and copy its entire contents into the authoring chat. Each file includes the article-specific thesis, mechanism, three developed example plans, individual illustration briefs, research leads, exact ten-section outline, repository integration instructions, and verification requirements. No other prompt file needs to be attached.

The prompts ask for a complete draft article and actual illustrations when the authoring environment supports them. Running the prompts, generating articles, and publishing them are separate actions; this package does not do those things.

The agreed visual direction is **light technical illustrations on white**, following the approved Architecture drawing language. It is not the Graphic Design photographic comparison style. Figures use editable SVG, regular Helvetica Neue, fine lines, restrained green, direct labels, and separate desktop/phone compositions. The fixed light figure surface remains white in dark appearance.

All articles use the established Machine Learning / Data Engineering ten-section progression. Team examples concern technical coordination and Agile delivery; HR topics and guided practices are excluded.

[Read the common editorial and illustration standard](shared-standard.md). The full standard is embedded in every standalone prompt; update those copies as well if changing the reference.

## Catalogue boundaries

The numeric order is the agreed 18-pattern catalogue. Pattern 6 is Bound the Task and pattern 17 is Make Changes Understandable, reflecting the engineering-only scope. Candidate article IDs are proposals and must be checked for existing equivalents before authors create canonical entries. Neighbor titles in prompts are not claims that those articles already exist.

Version control is addressed explicitly across task boundaries, parallel changes, checkpoints, traceable history, integration, and release. The prompts distinguish a backlog item, an agent task, a branch/workspace, a commit, a review unit, and a release. They require proportionate verification and preserve concurrent work.
