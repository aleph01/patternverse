# Statistics accuracy and consistency review

Reviewed 25 October 2026: all 42 published statistics articles, their worked examples, 84 desktop/phone illustrations, nine unique interactive examples, and the accompanying example data and figure generators. The 16 guided applications, including the three branching knowledge checks, were retained unchanged.

The worked numerical results were consistent with their stated teaching models. The fixes concern interpretation, one misleading uncomputed value, rendering, and package metadata. This review checks the published examples and their assumptions; fictional examples do not validate a real study.

## Findings and fixes

1. **Uncomputed simulation displayed as zero.** The multiple-testing explorer showed a simulated 0% before running any experiments, although its text said no simulation existed. It now displays only the theoretical result until a simulation runs. Changing the test count or resetting clears the simulation and removes that bar. Both static previews were regenerated.
2. **Grid optimum confused with the continuous optimum.** The ridge illustration includes a smooth validation-error curve, whose minimum is at penalty 9, with MSE 36/13 ≈ 2.7692. The four-point grid instead selects penalty 12, with MSE 2.8125. The article and alternative text now distinguish these quantities; a numerical regression check covers the distinction.
3. **Integer-score extrapolation needed an explicit assumption.** The threshold example recovers a six-point jump using its specified straight lines, but no untreated outcome is observed at score 80. The article and caption now explain that bridging the gap from 79 to 80 requires an assumption. With a genuinely discrete running variable, continuity alone does not identify the cutoff effect. See [Cattaneo and Titiunik, section 3.5](https://rdpackages.github.io/references/Cattaneo-Titiunik_2022_ARE.pdf).
4. **Instrument strength needed its uncertainty.** A small first-stage difference alone does not establish weak identification. The instrument article now distinguishes effect magnitude from precision and explains why an adequately large study can estimate a small first stage precisely. It retains the warning about unstable ratios and adds the [Stock–Yogo methodological reference](https://www.nber.org/papers/t0284).
5. **Bias arithmetic needed a narrower scope.** The causal sensitivity example now explicitly concerns an unadjusted treated-minus-control mean contrast under the stated additive model. Its prevalence-gap formula should not be applied to an already adjusted regression using raw group prevalences. The fixed-bias intervals remain conditional on known scenario values, as before.
6. **Dashed paths retraced themselves.** Four older SVG generators closed two-point strokes, causing the return stroke to fill or alter dash gaps. Twenty-four desktop/phone illustrations contained affected dashed paths. The generators now leave those strokes open; their regenerated output also normalizes solid two-point strokes. This restores the intended distinctions in forecasts, synthetic controls, monitoring limits, equivalence bounds, and other reference lines. This stroke repair leaves numerical values and chart coordinates unchanged. Separately, the precision-planning marker now uses the actual half-width at rounded-up n = 62 (about 2.987 points), rather than placing it exactly on the three-point target.
7. **A phone legend was clipped.** The final posterior-mean label in the updating-beliefs phone illustration extended below the SVG boundary. Tighter legend spacing keeps all four labels inside the image. A real-browser check now covers text bounds in all 84 illustrations.
8. **Package metadata had drifted.** Twenty older article word counts had not incorporated subsequent additions. Counts now use one convention throughout: article body before the sources heading, including captions, tables, and widget specifications, excluding sources and guided applications. The censoring metadata now points to the same Kaplan–Meier reference as the article. Source lists and word counts agree for all 42 records.

## Verification

All 100 focused numerical, corpus, collection, practice-runtime, and rendering tests pass. All 20 desktop/phone browser checks pass; two intentional skips avoid running the phone accordion on desktop or repeating the 84-SVG check on the phone project. Browser measurements find no clipped text in any of the 84 illustrations. Type checking reports zero errors and warnings. The production build, public-build checks, changed-file lint, and formatting checks pass. All 42 source lists and article word counts match metadata. All original guided-application source blocks are unchanged. Figures were also visually inspected, including before/after comparisons of forecasts, synthetic controls, and the corrected posterior legend. Changes remain local; no publication or deployment was performed.

Run the numerical tests, Svelte checks, and production build sequentially because their tooling can regenerate shared SvelteKit files. An overlapping test/build run produced different bootstrap identifiers in prerendered HTML and client code; a sequential rebuild restored matching identifiers before the final browser run. No application-source change was needed.
