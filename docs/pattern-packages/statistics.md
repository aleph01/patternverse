# Statistics Field Guide

42 independently written articles, 22 subject collections, one curated Statistical Traps collection, five section indexes, two reading paths, and one guide index. Nine self-contained interactive examples illustrate fixed, stated assumptions, with static SVG previews visible before interaction. Every article has a visible illustration with an authored phone layout. The articles have no interactive practices.

The prose uses an accessible opening and worked examples, followed by advanced notes. Articles are deliberately focused rather than full textbook chapters. All numerical scenarios are fictional and their assumptions are stated. Source links provide deeper technical development.

## Editorial boundaries

The package provides a broad practical first edition. It does not claim comprehensive coverage of specialized spatial statistics, extreme-value theory, adaptive experimental design, advanced longitudinal g-methods, or every estimator. Causal articles explain the identification argument separately from calculation. Prediction is distinguished from intervention; confidence, posterior, and predictive uncertainty are distinguished in the articles.

Rich recommendation metadata and source records live in `statistics.json`, following the existing package convention. No new schema fields, dependencies, routing, inference service, or model-selection automation are introduced. Existing widget support is reused.
