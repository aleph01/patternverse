# Graphic Design concise article rollout

Completed the remaining 36 core articles on 29 October 2026, following approval of the three-article pilot. All 39 core patterns now use the concise visual-led reading structure. The already compact supporting Contrast as a Foundation concept remains unchanged.

## Editorial changes

- Short openings establish a recognizable problem and the distinct intervention before the main visual.
- A single “What to notice” explanation combines diagnosis, change and mechanism. Two shorter variations retain different failures, alternatives and tradeoffs.
- Practical uses and limits replace repeated general explanations. Related patterns now explain neighboring decisions briefly; compact source lists retain original destinations.
- Consolidated techniques and their legacy entry points remain, including scale, guiding the eye, proportional relationships, deliberate grid breaks, type pairing, color roles, grayscale testing, background control and silhouettes.
- Additional controlled comparisons remain accessible outside the main lesson. No artwork, widget, site component or publication metadata changed.
