## Specific musical checks

- **Seven Nation Army:** the selected riff begins E–E–G–E–D–C–B, with its unequal durations intact. It repeats over retained kick/pedal-hi-hat parts. The original octave-down guitar tone is represented by the local bass sound.
- **Billie Jean:** the selected bass begins F♯–C♯–E–F♯–E–C♯–B–C♯ and repeats against the basic drum lanes.
- **Lean on Me:** the melody starts C–C–D–E–F and returns by steps. The provider stores this line on an alto-sax program; its piano accompaniment is retained and the melody plays on sampled piano.
- **Get Lucky:** the retained chord/bass reference outlines B minor–D major–F♯ minor–E major over one four-bar cycle. The unrelated C-major header is not used as the key label.
- **No Surprises:** the reduction contains F-major A/C material and the B♭–D♭–F borrowed minor-iv figure. D♭ is respelled from the MIDI importer’s C♯ without changing pitch or timing.
- **Scarborough Fair:** the picked guitar excerpt contains E, F♯, G, A, B, C♯ and D, with an E centre. This supports the E-Dorian listening cue. The provider demo is a guitar introduction; it does not supply the sung melody or Canticle counterpoint.
- **Take Five:** source meter stays 5/4. The selected four bars contain melody, piano accompaniment and bass. Brush/ride percussion is omitted because the basic drum engine does not reproduce those timbres.
- **Fantaisie-Impromptu:** a representative quarter-note span has four right-hand starts against three left-hand starts. The ratio is 4:3; the score supplies the C♯-minor key label.
- **Avril 14th:** the community export contains a merged piano arrangement. Eight zero-duration note events are removed from the playback copy; all 481 positive-length notes retain their pitches, start ticks, duration ticks and velocities. The original export and a repair record are retained. Its register and one-track layout are disclosed, and it is not presented as an authoritative two-hand transcription.

## Local playback and reproducibility

The six open-edition source files are in `docs/musical-composition/midi-research/`. Nine modern provider/community files are local research copies under ignored `.local/music-repertoire/`; they are not included in the application or its public build. Their source links and hashes are recorded in the JSON audit. An alternate folder can be supplied with `MUSIC_DEMO_MIDI_DIR`; the older single-file `MUSIC_DEMO_SUPERSTITION_MIDI` override remains supported.

The source catalog, rather than an arbitrary path from the browser, controls which files the local fixture server can serve. A different checkout without those private local copies will expose its available open-edition examples; use `MUSIC_DEMO_FULL_LIBRARY=1` when validating this complete local library.
