# Archived Musical Composition course

Archived on 30 October 2026 at the user’s request. This version is retained for reference and is no longer the working curriculum.

[Download the source snapshot](course-snapshot.tar.gz) · [File inventory and checksums](manifest.json)

The snapshot preserves all 64 draft content entities, both recurring original examples, the existing course and collection plans, diagrams, musical data, and the music-player implementation available at the reset. Paths inside the archive are relative to the repository root. The manifest records each source file and its SHA-256 checksum.

Private downloaded MIDI files, piano sample binaries, dependencies and unrelated application work are outside the bundle. Existing local assets remain in place. The bundle is a source reference, not a standalone application release.

The shared player remains reusable infrastructure. Examples and patterns can be reconsidered individually during the new design; the old course sequence, counts and collections have no authority over it.

The fresh working brief is `docs/music-course/README.md`.
