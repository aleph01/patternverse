# Graphic Design consolidation

**Subsequent authorship:** Establish a Shared Visual Language, Develop Distinctive Visual Cues and Build Reusable Templates are now illustrated drafts. The current collection has 39 authored core patterns and no remaining planned core briefs; the counts below record the consolidation baseline.

Implemented locally on 28 October 2026. The collection now has **36 authored core patterns**, **three planned system-level briefs**, and **one supporting foundation guide**. All authored content retains draft status.

## What changed

The former 58-candidate inventory is now a 39-core plan. Nineteen authored entries have been absorbed, redistributed or reclassified. Their original text and metadata remain in the authoring archive; they no longer compete as separate patterns in the reader’s index.

| New core article                                                                                                   | Material combined                                                 |
| ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| [Establish Visual Hierarchy](../content/patterns/graphic-design-establish-visual-hierarchy.md)                     | Focal Point and Levels of Importance; scale is a named technique. |
| [Use Spacing to Express Relationships](../content/patterns/graphic-design-use-spacing-to-express-relationships.md) | Negative Space, Consistent Spacing and Proximity.                 |
| [Build a Purposeful Palette](../content/patterns/graphic-design-build-a-purposeful-palette.md)                     | Palette Limitation, Complementary Contrast and Analogous Harmony. |

Each combined article develops three complementary transformations. Additional comparisons remain available through descriptive full-size and stacked-view links, rather than being concatenated into a much longer article.

**Frame the Content** was redistributed between enclosure and figure–ground separation. **Guide the Eye** was redistributed between reading flow and exact image annotation. **Contrast as a Foundation** is now a short concept guide that helps select a repair. **Test in Grayscale** is a named diagnostic within Value Contrast, with meaning-beyond-color examples owned by that pattern.
